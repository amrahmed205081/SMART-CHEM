# SmartChem

Frontend-only corporate website for SmartChem — Smart Chemical Solutions.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- React Router

## Run locally

```bash
npm install
npm run dev
```

Then open the printed local URL.

## Data sources

All products, partner names, technical fields, logos and contact details come from the supplied SmartChem documents and assets. No invented product codes or specifications were added.

Titanium dioxide is mentioned in the company profile as part of the offering. No TiO2 grade list was included in the source files, so the category explains that and does not invent products.
